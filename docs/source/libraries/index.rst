SDKs and client repositories
===========================

Generated SDK reference and examples are hosted on
`CDA GitHub Pages <https://usace.github.io/cwms-data-api/>`_. The site identifies
the CDA and package versions and retains release-specific documentation.

Generated SDK source lives in
`CDA clients <https://github.com/USACE/cwms-data-api/tree/develop/clients>`_.
Higher-level clients can add data analysis, conversions, and application workflows.

* `cwmsjs generator <https://github.com/USACE/cwms-data-api/tree/develop/clients/typescript>`_
* `CWMS Python <https://github.com/HydrologicEngineeringCenter/cwms-python>`_
* `CWMS CLI <https://github.com/HydrologicEngineeringCenter/cwms-cli>`_
